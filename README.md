# BIOSWARE Cinema

A self-hosted media-library and browser player prototype for a private local movie collection.

The backend indexes configured media folders, prepares metadata and thumbnails, and supports browser playback workflows including HLS/transcoding helpers.

## Highlights

- Local media library indexing
- Browser-based catalogue
- HLS playback support
- FFmpeg integration
- Thumbnail generation
- Tests for core media workflows

## Privacy

The repository contains no movies, watch history, local database, cache or machine-specific library paths. Configure your own folders using config.example.json.

## Stack

Python, JavaScript, HTML, CSS, HLS.js, FFmpeg.
